# Blog Article Page (HTML-Only Project)

A fully semantic, accessible **Blog Article Page** built using **only HTML** — no CSS and no JavaScript.  
This project demonstrates strong fundamentals in **semantic tags, accessibility, document structure, and clean HTML markup**.

---

## Features

### Semantic Layout Structure
The page is built with proper structural HTML elements:

- `header`
- `nav`
- `main`
- `article`
- `section`
- `aside`
- `footer`

These ensure correct document flow and improve accessibility and SEO.

---

### Article Content
The article includes:

- Title, author, publication date
- Multiple content sections
- Blockquote
- Ordered list
- Figure with caption
- Related links section
- Conclusion paragraph

---

### Sidebar (Aside)
The sidebar contains:

- Author bio
- Newsletter subscription form
- Quick stats (using definition lists)

---

### Table
A semantic, accessible table demonstrating:

- `caption`
- `thead`
- `tbody`
- Row headers with `th scope="row"`

---

### Forms
This project includes two fully structured forms:

1. Newsletter subscription form  
2. Reader comment form  

Each form uses:

- `<label>` correctly linked with `for`
- `<fieldset>` and `<legend>`
- Required fields
- Accessible field grouping

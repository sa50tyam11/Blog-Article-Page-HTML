📄 Blog Article Page (HTML-Only Project)
A fully semantic, accessible Blog Article Page built using only HTML — no CSS and no JavaScript.
This project showcases strong fundamentals in structuring content, using proper semantic tags, accessibility, and page organization.
🚀 Features
✅ Semantic Layout Structure
This project uses correct semantic HTML elements, including:
<header>
<nav>
<main>
<article>
<section>
<aside>
<footer>
These elements improve SEO, accessibility, and readability of your markup.
✅ Article Content Structure
The article includes:
Title, author, and publication date
Multiple sections with headings
Blockquote
Ordered list
Figure + caption
Conclusion section
Related links navigation
✅ Sidebar (Aside)
Useful complementary content:
Author bio
Newsletter subscription form
Quick stats
✅ Table
A semantic table with:
<caption>
<thead>
<tbody>
Row headers using <th scope="row">
This demonstrates your understanding of accessible table markup.
✅ Forms
The page includes two forms:
Newsletter subscription form
Reader comment form
Both follow best practices:
<label> linked with for
Accessible <fieldset> and <legend>
Required field indications
